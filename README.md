# Gabriel Costa

**`Full Stack Developer`**

Full Stack Developer focused on the **.NET and Angular ecosystem**, with a strong interest in building complete web applications and understanding the software development lifecycle as a whole. I work mainly with **C#, ASP.NET Core, Angular, TypeScript, SQL Server, and PostgreSQL**, while applying concepts such as REST APIs, Entity Framework Core, Clean Architecture, and CQRS.

I'm also interested in **DevOps and software infrastructure**, continuously expanding my knowledge of Docker, CI/CD, GitHub Actions, containers, and application delivery. I enjoy exploring how software moves beyond development — from architecture and testing to automation, deployment, and production environments.
